## 一、这个项目真正想解决什么

生成物理内容最容易犯两类错误，而它们**看起来最像对的**：

1. **公式抄错** —— 把 `s = vt` 写成 `s = v/t`、把 `Fb = ρgV` 写成 `Fb = ρgV²`
2. **规律说反** —— 「反射角等于入射角」写成「入射角等于反射角」（镜面转动时两者不等）

人一条条核不现实。但放进机器里，它们反而能被**完全自动地判死**。

所以这个项目的重点**不是内容本身**，而是**判定机制**：
怎么把「物理上对不对」变成「代码可以自动判定的东西」。

## 二、六类自动检查

每一条公式都要经过这六类检查，全部通过才允许进成品：

| 检查 | 抓什么 |
|---|---|
| **量纲一致性** | 等式两边的基本量指数必须完全一致 → 抓「写反、漏项、多乘一项」 |
| **单位标注** | 每个符号标注的单位要和公式推导出的量纲相符 |
| **数值代入** | 给一组自洽的情境参数，算出的数必须等于独立算出的参考值 |
| **变化方向** | 某参数增大时，结果该变大还是变小 → 抓「规律说反」 |
| **跨公式互证** | 同一情境下两条不同公式算同一个量，结果必须相同 |
| **极端参数扫描** | 参数在大范围连续取值，全程不许出现异常、NaN 或无穷 |

**初中特别加强的三类**（初中最常考、又最适合机器验）：

| 检查 | 例 |
|---|---|
| **单位换算** | `1 g/cm³ = 1000 kg/m³`、`1 kW·h = 3.6×10⁶ J`、`1 mL = 1 cm³` |
| **数量级合理性** | 「中学生质量约 50 kg」「人耳听觉范围 20～20000 Hz」——离谱就报错 |
| **图像读数** | v–t 图面积 = 位移、m–V 图斜率 = 密度，与直接计算互证 |

## 三、还有一层「质检」——查的是校验器管不到的东西

自动检查全绿**不等于内容正确**。所以还有一层质检，专门假设「成品有问题」：

| 环节 | 它在问什么 |
|---|---|
| **覆盖门槛** | 内容有没有被真正考过？每条知识点至少 2 项数值代入、1 项极值扫描、1 项跨公式互证 |
| **独立复算** | 参考值是不是被"凑"出来的？—— 换一套**完全不同的代码**（Python 原生 `ast`）把每个数值重算一遍 |
| **成品一致性** | 网页里的内容，和源文件是不是同一份？ |
| **内容自洽性** | 正文里随手写的符号，本卡片符号表里有没有？ |

**独立复算是最关键的一条**：如果有人把公式写错、再把"参考值"也改成错误公式算出来的数，
校验器会认为一切正常 —— 因为它比的就是这两者。**换一套代码重算，是唯一能发现这种情况的自动手段。**

```

```

## 五、怎么用

无需安装任何第三方库，只需要 Python 3。

```bash
# 1. 校验初中全部内容（结构 + 六类物理检查）
python work/validate.py work/kb_junior

# 2. 出成品网页
python work/build_site.py work/kb_junior ../outputs/初中物理知识库.html

# 3. 出速查版
python work/build_lite.py work/kb_junior ../outputs/初中物理速查.html
```

**这套流水线是通用的**：同一份代码既能跑高中（`work/kb/`，21 章 1535 项校验），
也能跑初中（`work/kb_junior/`，18 章 549 项校验）—— 靠的就是 `validate.py` /
`build_site.py` 都支持传目录参数。

## 六、两条刻意的设计取舍

**① 显示与校验解耦。**
符号名是给机器用的（`v_avg` 能进表达式、能查表），但人看到的应该是教材写法（**v̄**）。
所以数据里一个字不改，只在「渲染成 HTML」的那一刻翻译。
好处：加显示规则**不可能影响任何校验结论**。

**② 学会说"这条我判不了"。**
概念性错误（比如「物体运动就一定有力」）不体现为公式写错，
硬凑一个能跑的检查上去只会制造假安心。
这类一律标注「**人工审核**」—— 96 条常见错误里有 39 条是这么标的，
**宁可承认边界，也不假装全覆盖**。

## 七、已知限制

- **自动检查覆盖的是"能被公式表达的错误"。** 表述是否地道、例子是否恰当，机器判不了。
- **本仓库按 2024 新版教材编排。** 如果你用的是旧版，章节归属和顺序会不一样。
- **本仓库是"对外展示版"**：只包含内容、流水线与成品；日常协作的过程记录不在此仓库内。
